```
def abs(a):
    return a if a >= 0 else -a

def max(a, b):
    return a if a >= b else b

def max_abs(a, b):
    return max(abs(a), abs(b))

```

Доказательство для функции `abs`.

Тройка Хоара:

{P: x = n} a if a >= 0 else -a {Q: x = |n|}

Обе ветки `if` верны так как:

- если `a >= 0`, то `a == |a|`
- если `a < 0`, то `-a == |a|`

Соответствено, и для всего `abs` Q выполняется всегда.


Доказательство для функции `max`.

Тройка Хоара:

{P:a = n, b = m} r := (a if a >= b else b) {Q: r = max(n, m)}

- по `a >= b`, результат `r = a`, тоесть `max(a, b)`
- по `a < b` результат `r = b`, тоесть `max(a, b)`
- третьего не дано, соответственно `max` корректно


Доказательство для функции `max_abs`.

Тройка Хоара:
{P: a = n, b = m} d := abs(a); c := abs(b); r := max(d, c) {Q: r = max(|n|, |m|)}

Программа не содержит новых операций, корректность операций и по свойству композиции корректность считается доказанной.

```
{P} S1 {Q1} {Q1} S2 {Q2}
{P} S1 S2 {Q2}
```
